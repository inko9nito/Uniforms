# Item photos

Drop product photos here, then reference them from `inventory.md`'s **Image**
column as `images/your-file.jpg`.

Tips:
- One clear photo per item works best (ideally just that item, on a plain background).
- Any size is fine — the site auto-crops to a consistent card area.
- Supported: `.jpg`, `.png`, `.webp`.

Example: a file at `public/images/navy-polo-ys.jpg` is referenced as
`images/navy-polo-ys.jpg` in the Image column.
