# FCA Uniform Resale — Inventory

**This table is the live inventory for the website.** Edit it right here in
GitHub, then commit to `main` — the public page rebuilds and updates
automatically within a couple of minutes.

How to edit:

- **Status** — set to `Sold` to gray the item out on the site, or `Available` to list it.
- **Schools** — `Carrollton`, `Frisco`, or `Both`. Use `Both` for anything that
  works at either campus (e.g. **sweaters**); those items appear under *both* the
  Carrollton and Frisco tabs.
- **Condition** — short note shown under the item (leave blank if none). Long notes
  truncate on the card and show in full on hover.
- **Image** — optional. Put a photo in the `public/images/` folder of this repo and
  reference it as `images/your-photo.jpg`, or paste a full image URL. Leave blank to
  use the default garment illustration. Photos are auto-cropped to fit the card.
- To **add an item**, copy a row and change the values. To **remove one**, delete its row.
- Prices are dollars, numbers only (no `$`).

Only people with write access to this repository can commit changes here, so
the public status can only be changed by you.
