# FCA Uniform Resale — Inventory

**This table is the live inventory for the website.** Edit it right here in
GitHub, then commit to `main` — the public page rebuilds and updates
automatically within a couple of minutes.

How to edit:

- **Section** — `Girls`, `Boys`, or `Unisex`. Drives the Gender filter and the page
  heading. Girls/Boys items are shown with that prefix (e.g. "Girls Navy polo");
  `Unisex` items (like the Spirit shirt) keep their plain name.
- **Qty** — how many of this item are available. Lower the number as items sell;
  set it to `0` and the listing shows **Sold out** and grays out. (Blank = 1.)
- **Schools** — `Carrollton`, `Frisco`, or `Both`. Use `Both` for anything that
  works at either campus (e.g. **sweaters**); those items appear under *both* the
  Carrollton and Frisco tabs.
- **Condition** — short note shown under the item (leave blank if none). Long notes
  truncate on the card and show in full on hover.
- **Image** — optional. Put photos in the `public/images/` folder of this repo and
  reference them as `images/your-photo.jpg`, or paste full image URLs. **Add several
  photos** by separating them with commas — they become a swipeable gallery on the
  item's detail view. Leave blank to use the default garment illustration. Photos are
  auto-cropped to fit the card.
- **Link** — optional. The URL of the original store listing where you bought the item.
  Shown as a "View original listing" link on the item's detail view.
- To **add a listing**, copy a row and change the values. To **remove one**, delete its row.
- Keep items on separate rows when their condition differs (e.g. a clean polo vs. a
  blemished one), so buyers see the distinction.
- Prices are dollars, numbers only (no `$`).

Only people with write access to this repository can commit changes here, so
the public listings can only be changed by you.
