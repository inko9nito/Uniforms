# FCA Uniform Resale — Inventory

**This table is the live inventory for the website.** Edit it right here in
GitHub, then commit to `main` — the public page rebuilds and updates
automatically within a couple of minutes.

How to edit:

- **Status** — set to `Sold` to gray the item out on the site, or `Available` to list it.
- **Schools** — `Carrollton`, `Frisco`, or `Both` (e.g. sweaters that work at either campus).
- **Condition** — short note shown under the item (leave blank if none).
- To **add an item**, copy a row and change the values. To **remove one**, delete its row.
- Prices are dollars, numbers only (no `$`).

Only people with write access to this repository can commit changes here, so
the public status can only be changed by you.
